# 刘易枋个人网站 2.0

这是新版个人作品集网站，采用 React、Vite、Framer Motion 和液态玻璃风格 UI。

- 线上入口：<https://liuyifang-0320.github.io/CV/>
- 旧版已保留在 `legacy-v1` 分支和 `portfolio-v1-legacy` 标签
- 可维护源码在 `source/`
- 根目录 `index.html` 与 `assets/` 是 GitHub Pages 直接访问的构建产物

本地开发：

```bash
cd source
npm install
npm run dev
```

重新构建：

```bash
cd source
npm run build
```
